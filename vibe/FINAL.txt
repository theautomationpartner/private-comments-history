CAMBIO 1 — styles.css: las tarjetas no tienen fondo ni borde
===============================================================================

styles.css usa nombres de variables CSS de monday que NO existen en esta app. Cuando una variable
CSS no existe, la declaración entera se descarta: el fondo queda transparente y el borde desaparece
por completo. Por eso las tarjetas se ven como texto suelto.

Las variables que SÍ existen son las definidas en el :root del proyecto, y van envueltas en hsl().

Hacé este reemplazo en TODO styles.css, en todas las apariciones:

  var(--primary-background-hover-color)   ->   hsl(var(--card))
  var(--ui-border-color)                  ->   hsl(var(--border))
  var(--primary-text-color)               ->   hsl(var(--foreground))
  var(--secondary-text-color)             ->   hsl(var(--muted-foreground))
  var(--disabled-background-color)        ->   hsl(var(--muted))

Y verificá que estas tres reglas queden con el borde bien declarado:

  .entry-card   { background: hsl(var(--card)); border: 1px solid hsl(var(--border)); }
  .summary-card { background: hsl(var(--card)); border: 1px solid hsl(var(--border)); }
  .empty-card   { background: hsl(var(--card)); border: 1px solid hsl(var(--border)); }
